🌌 BLOCK UNIVERSE 3.0 — THE NEXT EVOLUTION

YOUR ADVENTURE STARTS HERE

Welcome to the next evolution: a bigger-feeling 3D block adventure with rugged biomes, a hidden dungeon, upgraded crafting, villages, dangerous enemies, and the Nether King. This is an experimental browser prototype; online graphics and multiplayer need internet.

Controls: WASD to move, mouse to look, Space to jump over raised blocks, left-click to mine, right-click to build. Explore Forest, Ocean, Swamp, Grassland, the new Frostlands and the dangerous Nether. Discover a dungeon, meet village NPCs, mine rare ores, craft upgraded gear, and battle the Nether King. Multiplayer room controls are included, but connections depend on the network.

Opening your world… If the world does not appear, wait a moment; if it stays black, use the error message below to help us fix it.
🌐 MULTIPLAYER ROOM (BETA)
Anyone can enter alone. Choose a room code and click Create room or Join room; everyone who uses the same code enters the same room. You can play while waiting for others. Both players need internet for this online version.
